L’ARBRE DES DEVOIRS — DA 1 THE ENCHANTED TREE

INSTALLATION SIMPLIFIÉE (un seul fichier)
1. Décompresser cette archive.
2. Ouvrir le dépôt https://github.com/brot2you/Arbre-des-devoirs
3. Sauvegarder l'ancien index.html en cas de retour arrière.
4. Importer le nouveau index.html à la racine du dépôt (remplacer l'ancien).
5. Valider / Commit changes et recharger la page GitHub Pages (Ctrl+F5).

Tout le CSS, tout le JavaScript et les illustrations sont inclus dans cet index.html.
Aucun autre fichier n’est nécessaire. Les polices externes sont facultatives.

24 situations regroupées dans les 7 activités initiales, conseils,
premiers petits pas, questions de méthode, favoris, retour d'expérience,
feuilles de progression illustrées et carnet personnel enregistré en local.
Aucun compte ni envoi de données personnelles.

Cette livraison est une nouvelle version des fichiers, pas une modification
automatique du dépôt distant.
